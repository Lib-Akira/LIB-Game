# Library Quest: ภารกิจพิชิตห้องสมุด

เกมตอบคำถามพร้อมระบบหัวใจ (Life System) สำหรับกิจกรรมของห้องสมุด เล่นได้ทันทีในเบราว์เซอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

## โครงสร้างไฟล์

```
library-quest/
├── index.html      หน้าเกมหลัก (3 หน้าจอ: เริ่มต้น / เล่น / จบภารกิจ)
├── style.css        ดีไซน์และสีทั้งหมด
├── questions.js      คลังคำถาม — แก้ไข/เพิ่ม/ลบคำถามที่ไฟล์นี้ไฟล์เดียว
├── script.js        กติกาเกม: หัวใจ, คะแนน, สุ่มคำถาม, รหัสรางวัล
└── README.md
```

## กติกาที่ใช้ในเกม

1. เริ่มต้นด้วยหัวใจ 3 ดวง
2. ตอบผิด 1 ข้อ หักหัวใจ 1 ดวง
3. หัวใจหมด (0 ดวง) = จบภารกิจในรอบนั้นทันที
4. ตอบคำถามครบทุกข้อโดยหัวใจไม่หมด → หน้าจอจะแจ้งให้ไปรับของรางวัลที่เคาน์เตอร์ห้องสมุด
5. หาก Game Over สามารถกดเริ่มใหม่ได้ไม่จำกัดจำนวนครั้ง คำถามจะถูกสุ่มลำดับใหม่ทุกรอบ

## วิธีแก้ไขคำถาม

เปิดไฟล์ `questions.js` แล้วแก้ไขในอาเรย์ `QUESTIONS` แต่ละข้อมีรูปแบบ:

```js
{
  text: "คำถามของคุณ?",
  choices: ["ตัวเลือก A", "ตัวเลือก B", "ตัวเลือก C", "ตัวเลือก D"],
  answer: 1   // index ของคำตอบที่ถูก (0=A, 1=B, 2=C, 3=D)
}
```

เพิ่มหรือลบ object ในอาเรย์ได้ตามต้องการ ระบบจะสุ่มลำดับคำถามให้อัตโนมัติทุกครั้งที่กด "เริ่มภารกิจ"

## ทดสอบบนเครื่องตัวเอง

ไม่ต้องติดตั้งอะไร เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือถ้าต้องการรันผ่าน local server (แนะนำ เพราะบางเบราว์เซอร์บล็อกการโหลดไฟล์ .js แบบ local):

```bash
cd library-quest
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## นำขึ้น GitHub และเผยแพร่ด้วย GitHub Pages (ฟรี — ทำผ่านเว็บเบราว์เซอร์ล้วนๆ ไม่ต้องใช้คำสั่งใดๆ)

วิธีนี้ไม่ต้องติดตั้งโปรแกรมอะไรเพิ่ม ใช้แค่เว็บเบราว์เซอร์กับไฟล์ 5 ไฟล์ที่ได้รับไปเท่านั้น

### ขั้นตอนที่ 1 — สมัครบัญชี GitHub (ข้ามได้ถ้ามีอยู่แล้ว)
1. เข้าเว็บ https://github.com
2. กด **Sign up** มุมขวาบน แล้วกรอกอีเมล ตั้งรหัสผ่าน และตั้งชื่อผู้ใช้ (username) ตามขั้นตอนบนหน้าจอ
3. ยืนยันอีเมลตามที่ระบบแจ้ง แล้วเข้าสู่ระบบ (Sign in)

### ขั้นตอนที่ 2 — สร้าง repository ใหม่
1. เมื่อ login แล้ว ให้เข้าลิงก์ https://github.com/new โดยตรง
2. ช่อง **Repository name** พิมพ์ว่า `library-quest`
3. เลือกวงกลม **Public** (ให้คนอื่นเข้าเล่นเกมได้)
4. **ไม่ต้อง** ติ๊กช่อง "Add a README file" หรือช่องอื่นใดๆ ด้านล่าง
5. เลื่อนลงล่างสุด กดปุ่มสีเขียว **Create repository**
6. ระบบจะพาไปหน้า repository เปล่าๆ ที่มีคำแนะนำเป็นภาษาอังกฤษ — ข้ามไปทำขั้นตอนถัดไปได้เลย

### ขั้นตอนที่ 3 — อัปโหลดไฟล์เกมทั้งหมด
1. ในหน้า repository ที่เพิ่งสร้าง มองหาลิงก์ข้อความสีน้ำเงินที่เขียนว่า **uploading an existing file** (อยู่ในบรรทัดคำแนะนำตรงกลางหน้า) แล้วกด
   - ถ้าหาไม่เจอ ให้มองหาปุ่ม **Add file** มุมขวาบนของรายการไฟล์ แล้วเลือก **Upload files** จากเมนูที่เด้งลงมา
2. จะเจอกล่องสีเทามีข้อความ "Drag files here to add them to your repository"
3. ลากไฟล์ทั้ง 5 ไฟล์ (`index.html`, `style.css`, `questions.js`, `script.js`, `README.md`) จากโฟลเดอร์ในเครื่องคอมพิวเตอร์ มาวางในกล่องนี้ทีเดียวพร้อมกัน
   - หรือกดคำว่า **choose your files** ในกล่อง แล้วเลือกไฟล์ทั้ง 5 ไฟล์จากหน้าต่างเลือกไฟล์
4. รอสักครู่ให้ไฟล์อัปโหลดขึ้นแถบสถานะจนครบ 5 ไฟล์
5. เลื่อนลงมาล่างสุด ช่อง "Commit changes" ปล่อยข้อความเดิมไว้ได้ (หรือพิมพ์ "อัปโหลดไฟล์เกม")
6. กดปุ่มสีเขียว **Commit changes**
7. หน้าเว็บจะกลับมาแสดงรายการไฟล์ทั้ง 5 ไฟล์ที่อัปโหลดสำเร็จ

### ขั้นตอนที่ 4 — เปิดใช้งาน GitHub Pages ให้เกมมีลิงก์เว็บ
1. ที่หน้า repository เดิม มองหาแถบเมนูด้านบน แล้วกด **Settings** (มีไอคอนรูปเฟือง อยู่ขวาสุดของแถบ)
2. เมนูด้านซ้ายมือของหน้า Settings เลื่อนหาแล้วกด **Pages**
3. ในหัวข้อ **Build and deployment** จะมีช่อง **Source** ให้เลือก **Deploy from a branch** (ปกติเป็นค่าเริ่มต้นอยู่แล้ว)
4. ใต้หัวข้อ **Branch** จะมีสองช่องแบบ dropdown: ช่องแรกเลือก **main** ช่องที่สองเลือก **/ (root)**
5. กดปุ่ม **Save**
6. รอประมาณ 1-2 นาที แล้วรีเฟรชหน้าเดิม จะเห็นข้อความสีเขียวขึ้นว่า "Your site is live at..." พร้อมลิงก์เว็บ

ลิงก์เว็บของเกมจะเป็นรูปแบบ:
```
https://<ชื่อผู้ใช้ของคุณ>.github.io/library-quest/
```
คัดลอกลิงก์นี้ไปแชร์หรือทำ QR code แจกในกิจกรรมได้เลย

### วิธีแก้ไขคำถามภายหลัง (เช่น เพิ่ม/แก้ข้อสอบ)
1. เข้าไปที่ repository บน GitHub แล้วกดคลิกไฟล์ **questions.js**
2. กดไอคอนรูปดินสอ (Edit this file) มุมขวาบนของกล่องแสดงโค้ด
3. แก้ไขข้อความคำถามตามต้องการในหน้าเว็บได้เลย (ดูรูปแบบคำถามหัวข้อถัดไป)
4. เลื่อนลงล่างสุด กดปุ่มสีเขียว **Commit changes**
5. เว็บที่เผยแพร่ไว้จะอัปเดตอัตโนมัติภายในไม่กี่นาที ไม่ต้องอัปโหลดใหม่ทั้งหมด

## โหมดแข่งเวลา (สำหรับกิจกรรมปฐมนิเทศ)

เกมเวอร์ชันนี้ปรับเป็นโหมดแข่งขันแล้ว มีระบบดังนี้:

- **หัวใจ 3 ดวง** — ตอบผิดหรือหมดเวลา หักหัวใจ 1 ดวงต่อครั้ง
- **จับเวลาข้อละ 10 วินาที** — มีแถบนับถอยหลังในหน้าเล่นเกม (เขียว → ส้ม → แดง เมื่อเวลาใกล้หมด) หมดเวลาโดยไม่กดตอบ นับเป็นตอบผิดอัตโนมัติ
- **ลงทะเบียนก่อนเล่น** — ผู้เล่นต้องกรอกชื่อ-นามสกุล และรหัสนักศึกษา ก่อนกด "เริ่มตอบคำถาม" ระบบจะเริ่มจับเวลารวมทันทีที่กดปุ่มนี้
- **คำถามลำดับเดียวกันทุกคน** — เพื่อความยุติธรรมในการแข่งเวลา (ปิดการสุ่มลำดับคำถามไว้แล้ว ดูตัวแปร `CONFIG.RANDOMIZE_QUESTIONS` ในไฟล์ `script.js` หากต้องการเปิดกลับ)
- **ตัดสินผู้ชนะแบบ First-come, first-served** — ผู้ที่ตอบครบทุกข้อถูกต้อง (หัวใจไม่หมด) และ **ส่งผลถึงระบบเร็วที่สุด** คือผู้ชนะ

⚠️ **ข้อควรระวังเรื่องความยุติธรรม**: เวลาที่โชว์ในเกม ("เวลาที่ใช้: 00:23") คำนวณจากนาฬิกาของเครื่องผู้เล่นเอง ซึ่งทางทฤษฎีมีคนแก้ไขนาฬิกาเครื่องตัวเองโกงได้ วิธีที่แม่นยำและยุติธรรมกว่าคือ **ใช้ลำดับแถวที่ข้อมูลมาถึง Google Sheet เป็นตัวตัดสิน** เพราะเวลานั้นถูกบันทึกจากฝั่งเซิร์ฟเวอร์ (Google) ไม่ใช่จากเครื่องผู้เล่น — ให้เจ้าหน้าที่ดูจากแถวบนสุดที่ status เป็น `complete` เป็นผู้ชนะ ไม่ต้องอิงตัวเลขเวลาที่ผู้เล่นเห็นในเกม

### วิธีตั้งค่า Google Sheet เพื่อเก็บผลอัตโนมัติ (ฟรี ไม่ต้องมีเซิร์ฟเวอร์)

**ขั้นตอนที่ 1 — สร้าง Google Sheet**
1. เข้า https://sheets.google.com แล้วสร้างชีตใหม่ ตั้งชื่อเช่น "Library Quest ผลการแข่งขัน"
2. แถวแรก (Header) พิมพ์หัวคอลัมน์ไว้: `เวลาที่ระบบรับ | ชื่อ-นามสกุล | รหัสนักศึกษา | สถานะ | ตอบถูก | จากทั้งหมด | หัวใจที่เหลือ | เวลาที่ใช้ (ms)`

**ขั้นตอนที่ 2 — เขียน Apps Script รับข้อมูล**
1. ในชีตเดิม ไปที่เมนู **Extensions → Apps Script**
2. ลบโค้ดเดิมในกล่องแก้ไขทั้งหมด แล้ววางโค้ดนี้แทน:

```javascript
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    new Date(),               // เวลาที่ระบบ (เซิร์ฟเวอร์) รับข้อมูล — ใช้ตัวนี้ตัดสินผู้ชนะ
    data.name,
    data.studentId,
    data.status,
    data.correctCount,
    data.total,
    data.heartsRemaining,
    data.elapsedMs
  ]);
  return ContentService.createTextOutput(JSON.stringify({ result: 'success' }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

3. กดปุ่มบันทึก (ไอคอนแผ่นดิสก์) ตั้งชื่อโปรเจกต์อะไรก็ได้

**ขั้นตอนที่ 3 — Deploy เป็น Web App**
1. มุมขวาบน กดปุ่ม **Deploy → New deployment**
2. กดไอคอนรูปเฟืองข้าง "Select type" เลือก **Web app**
3. ตั้งค่า:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. กด **Deploy**
5. ระบบอาจขอให้ authorize สิทธิ์ — กด **Authorize access** แล้วเลือกบัญชี Google ของพี่ ถ้าเจอหน้าเตือน "Google hasn't verified this app" ให้กด **Advanced → Go to (ชื่อโปรเจกต์) (unsafe)** ได้ตามปกติ (เป็นสคริปต์ของพี่เอง ปลอดภัย)
6. คัดลอก **Web app URL** ที่ได้ (จะขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

**ขั้นตอนที่ 4 — ใส่ URL ลงในเกม**
1. เปิดไฟล์ `script.js` หาบรรทัด:
   ```javascript
   SHEET_ENDPOINT: ''
   ```
2. วาง URL ที่คัดลอกมาไว้ระหว่างเครื่องหมายคำพูด เช่น:
   ```javascript
   SHEET_ENDPOINT: 'https://script.google.com/macros/s/AKfycb.../exec'
   ```
3. บันทึกไฟล์ แล้วอัปโหลดขึ้น GitHub ทับไฟล์เดิม (ตามขั้นตอน Edit → วางทับ → Commit changes)

ทดสอบโดยเล่นเกมให้จบภารกิจ 1 รอบ แล้วเช็คว่ามีแถวใหม่ขึ้นใน Google Sheet หรือไม่

### เปรียบเทียบแพลตฟอร์มอื่นๆ (เผื่อไม่อยากดูแลสคริปต์เอง)

| แพลตฟอร์ม | ข้อดี | ข้อจำกัดสำหรับกิจกรรมนี้ |
|---|---|---|
| **เกมนี้ + Google Sheets** (แนะนำ) | ควบคุมหน้าตา/กติกาได้เต็มที่ ตรงกับที่ออกแบบไว้ทุกจุด ฟรี ไม่มีเซิร์ฟเวอร์ให้ดูแล | ต้องตั้งค่า Apps Script ครั้งแรก (ทำตามขั้นตอนด้านบนได้) |
| **Kahoot** | ตั้งค่าเร็ว มีกระดานผู้นำ (leaderboard) แบบเรียลไทม์ในตัว ผู้เล่นคุ้นเคยอยู่แล้ว | ปรับแต่งกติกา/หน้าตา/มาสคอตแบบนี้ไม่ได้ ฟีเจอร์จับเวลา+อันดับเป็นของแถมอยู่แล้วแข็งแรงกว่าที่เขียนเอง |
| **Google Forms + จับเวลา (Quiz mode)** | ทำง่ายที่สุด ไม่ต้องเขียนโค้ดเลย เก็บข้อมูลลง Sheet ให้อัตโนมัติ | ไม่มีระบบหัวใจ/เอฟเฟกต์เกม หน้าตาเป็นฟอร์มธรรมดา ไม่จับเวลาต่อข้อแบบนับถอยหลังจริง |
| **Mentimeter** | เหมาะกับโพลหรือคำถามเชิงความเห็นมากกว่า | ไม่เหมาะกับ quiz แบบมีคำตอบถูกผิด+จับเวลาแข่งกัน |

**สรุป**: ถ้าอยากได้ตัวเกมที่ปรับแต่งได้เต็มที่แบบนี้ พร้อมเก็บข้อมูลลง Google Sheet ก็ใช้ของที่มีอยู่นี้ต่อได้เลย แต่ถ้าอยากประหยัดเวลาตั้งค่าและไม่ติดใจเรื่องปรับแต่งหน้าตา **Kahoot** เป็นตัวเลือกที่ระบบจับเวลา+อันดับผู้ชนะทำงานได้แม่นยำและมีความพร้อมสูงกว่าในเวลาจำกัด

## แนวทางต่อยอด (ถ้าต้องการ)
- **กันเล่นซ้ำเพื่อรับรางวัลหลายรอบ**: เก็บสถานะ "เคยผ่านภารกิจแล้ว" ด้วย `localStorage` แล้วแจ้งเตือนที่หน้าจอจบภารกิจว่าเคยรับรางวัลไปแล้ว (ป้องกันเบื้องต้นเท่านั้น เจ้าหน้าที่หน้าเคาน์เตอร์ควรเช็กซ้ำอีกชั้น เช่น ขอดูหน้าจอ Mission Complete หรือขีดชื่อผู้เข้าร่วมไว้)
- **เพิ่มหมวดคำถาม**: แตกไฟล์ `questions.js` เป็นหลายชุดตามหมวด (เช่น กฎการยืม-คืน, การสืบค้น) แล้วสุ่มเลือกชุดตอนเริ่มเกม
